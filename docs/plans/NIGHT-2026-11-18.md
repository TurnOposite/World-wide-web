## The loop, for every item

1. Branch `claude/site-desk-<topic>` from `main`.
2. Read the code it touches; build it inside the mood board's guardrails (`docs/design/MOODBOARD-globe-trotter.md` §7).
3. Look at it: headless Chrome stills at 1440 × 900 and 390 × 844, reduced motion, keyboard only. Fix what is wrong.
4. `bash scripts/build-test.sh`, the whole thing. A red is fixed at its cause. A test that reads old source text is
   turned into a test of behaviour (`TESTS-REVIEW.md` section 3), never deleted to get green.
5. `WORKLOG.md`, `DECISIONS.md` where a choice was made, tick `BACKLOG.md`.
6. Fast-forward `main`, `node scripts/fire.mjs --yes` (push, CI, Vercel, tower), then check the live site serves it.
7. Stuck for long, or a red I cannot fix at its cause: push the branch, write down why, move to the next item.
